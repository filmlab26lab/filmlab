# 第二步：签名 + 装到 iPhone 15

前提：手上已经有一个 `FilmLab-test-unsigned.ipa`（路线见 `01_第一步_先拿到可安装的IPA.md`），
手机：iPhone 15，iOS 26.7.3，UDID `00008120-001A70160EF8A01E`。

两条签名路线，按你的情况选：

| | Apple ID 免证书签名 | 证书签名（.p12 + 描述文件） |
|---|---|---|
| 花钱 | 0 | 约 ¥68–168/年（买绑定你 UDID 的个人证书） |
| 有效期 | **7 天**，到期重签 | 1 年 |
| 能不能不碰 Apple ID 密码 | 不能（每次要登录一次） | 能 |
| 适合 | 现在只想验证「能不能跑起来」 | 长期每天装机自测 |

第一次验证链路，建议先用 **Apple ID 免证书签名**，7 天足够你判断这个测试包对不对。

---

## A. Apple ID 免证书签名（爱思助手）

1. 手机用数据线连电脑，解锁并在手机上点「信任这台电脑」。
2. 打开 **爱思助手** → 顶部 **工具箱** → **IPA 签名**（不要进错到「爱思商城」）。
3. 切到 **Apple ID 签名** 页 → **添加 IPA 文件** → 选 `FilmLab-test-unsigned.ipa`。
4. **添加 ID** → 填你的 Apple ID（免费账号就行）→ 密码那一步**你自己输**，我不代填。
5. 点 **立即签名** → 等 1～3 分钟。
6. 签完自动装到手机（也可以在「已签名应用」里点安装）。

装完手机上还差两步：

- **信任**：设置 → 通用 → VPN与设备管理 → 开发者 App → 点你的 Apple ID → 信任
- **开发者模式**：设置 → 隐私与安全性 → 开发者模式 → 打开 → 重启一次

---

## B. 证书签名（拿到 p12 + mobileprovision 之后）

1. 把 `xxx.p12` 和 `xxx.mobileprovision` 放进同一个文件夹，例如 `C:\Users\Administrator\Downloads\cert`。
2. 爱思助手 → 工具箱 → IPA 签名 → **证书签名** 页 → 导入 p12（输 p12 密码）+ 导入描述文件。
3. 添加 IPA → 立即签名 → 装到手机。

买证书下单前，把这四项报给卖家（这是唯一正确的规格）：

```
设备 UDID：00008120-001A70160EF8A01E
机型：iPhone 15，iOS 26.7.3
要：.p12 + .mobileprovision 一对，附 p12 密码，写明有效期
不要：所谓"免费企业证书"（几小时就被苹果吊销，全网一起掉签）
```

> 任何要你 Apple ID 密码的"证书卖家"都是骗子 —— 证书签名流程根本用不到 Apple ID。

拿到文件后，先验一遍再签（这三件事能让 90% 的坑提前暴露）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File Tools\检查IPA.ps1 `
  -Ipa "签名前的包.ipa" -Udid 00008120-001A70160EF8A01E -IosVersion 26.7.3
```

体检报告里「描述文件 / 绑定设备数 / 含本机：是」三项是重点：
- **含本机：否** → 这张描述文件没绑你的 UDID，签了也装不上
- **到期时间**早于今天 → 已经废了，找卖家换

---

## C. 装完怎么判断「测试包是成功的」

打开 FilmLab，逐项对照：

1. **底部四行设备信息**：机型 iPhone、系统 26.x、Metal 设备显示 `Apple A16 GPU` 之类的一行 —— 说明 App 起来了
2. **状态行是绿色「着色器编译成功」** —— 说明 `FilmTest.metal` 编进了包里且编译通过
3. **画面是 8 条色条 + 底部灰度渐变** —— 说明 Metal 管线在跑
4. **切换 Rec.709 / S-Log3 / D-Log / N-Log 四个按钮，画面应该完全一致**
   —— 这是本测试包的核心自检：Log 编码再解码可逆，所以四种模式画面必须一模一样。
   **如果有任何一档明显变亮、变暗或偏色，说明那条 Log 曲线写错了**，这正是这一步要抓出来的东西。
5. **拖颗粒 / Halation 滑块，画面有对应变化** —— 说明 uniform 传参正常

四项全过 = 链路通了，可以开始做相机页和照片/视频导入。
任何一项不过，把界面上那一行状态文字或录屏发我，我按现象定位。
